# Checklist de novo cliente

- [ ] Criar repositório independente com Use this template, sem branch ou fork por cliente.
- [ ] Confirmar nome, clínica, área de atuação, formação, registros e credenciais com o profissional.
- [ ] Substituir todo texto demonstrativo e revisar serviços e indicações reais.
- [ ] Substituir logo, retrato, favicon e imagem de compartilhamento.
- [ ] Revisar todas as mídias; manter somente materiais com autorização documentada.
- [ ] Não inventar depoimentos, avaliações, resultados ou contatos.
- [ ] Revisar textos alternativos, traduções ES/PT e fallback; testar idioma único quando aplicável.
- [ ] Conferir flags de seções e listas vazias; nenhuma âncora pode apontar para seção ausente.
- [ ] Testar WhatsApp real, mensagem em cada idioma, Instagram, e-mail, endereço e mapa.
- [ ] Confirmar que agendamento fica oculto enquanto não houver número real configurado.
- [ ] Revisar título, descrição, robots, URL canônica e imagem OG no HTML do build e na hospedagem.
- [ ] Procurar nome, telefone, identificadores, mídias e referências de qualquer cliente anterior em fontes, public e dist.
- [ ] Não copiar arquivos de referência privados ou histórico de outro cliente para o novo repositório.
- [ ] Não incluir .env, credenciais, chaves, tokens, node_modules ou dist no Git.
- [ ] Executar testes, build e preview; testar desktop/celular e movimento reduzido.
- [ ] Testar galeria ampliável, teclado, foco, FAQ e vídeos quando houver materiais.
- [ ] Criar publicação independente e confirmar domínio, variáveis, acesso e configuração de indexação.
- [ ] Habilitar Template repository manualmente no GitHub apenas no repositório da base.
